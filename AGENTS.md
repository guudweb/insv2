# Entregas WEB INSESO

En cada entrega actualice los textos nuevos o modificados en español, inglés, francés y portugués dentro de src/i18n. Incluya etiquetas, ayudas, errores, PDF y justificantes. Conserve los valores internos de opciones y rutas canónicas.

Antes de entregar ejecute npm run build (incluye la puerta de traducciones), node scripts/test-translations.mjs y las pruebas correspondientes a los módulos modificados. Los campos de las fichas adjuntas se verifican con node scripts/test-source-forms.mjs.

Los avisos institucionales de contacto y citas deben dirigirse a flora.bula@inseso.org mediante src/config/mail.mjs. Los justificantes del ciudadano conservan su correo. No afirme recepción real si solo se utilizó transporte simulado. No incluya .env, reservas reales ni credenciales en ZIP.
